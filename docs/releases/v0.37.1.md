# HotClip v0.37.1 — 标题与钩子:写法教义 + 本地质检 + 一次返工

## 问题在哪
此前提示词只给标题/悬念句**限字数**,不教怎么写,也不检查写完的结果。模型写套话
开头(`今天我们聊聊…` / `bugün sizlere…` / `in this video…`)、超出上限、整批一个
套路、标题里塞话题标签,或撞上平台风险词时,输出就这样交出去了——发布标题尤其
只有一次机会。

本版把「怎么挑开头句」的既有教义(它管的是逐字取自转写稿的 hook 字段)和「怎么
**写**」(模型自己生成的 title/teaser)分开:前者原样不动,后者补上教义与质检。

## 写法教义(`src/core/hook-craft.ts`,新)
- 五条写作机制,**三语各自原生**(不是互译):反常识打脸 / 停止式命令 / 直接提问 /
  结果反差 / 痛点点名;每条带一句规则和一组「反面 → 正面」例子。
- 四条总原则:只挖一个坑(答案留片里)、具体压过抽象(片内的名词/数字进标题)、
  前三个字定生死(不许以问候语开头)、只许诺片里真有的。
- 注入到所有产出**模型自己写**的文本的提示词:stage-1 的 title、moment 系统提示词、
  评审的悬念句、发布文案标题、变体包装。评审与变体用短版,避免挤掉评审本身。
- 教义块里**刻意不含**时长档位字符串(`8~40 秒` 等)——`highlightSystemPrompt` 会按
  档位对它们做原地替换,块混进去会被误伤;有测试钉住这一条。

## 本地质检(`src/core/hook-quality.ts`,新,零 API)
确定性的字符串判定,出口与提示词的上限一一对应:空 / 超长 / 套话开头 / 标题带
话题标签 / 平台风险词(复用违禁词 lint 的规则表,标题与简介一起扫)/ 整批近乎重复
(Dice 系数,中文按字 bigram、英土按削过虚词的词元)/ 角度撞车(≥3 条的批次里)。
- 土耳其语折叠用显式字母表(`İ→i`、`I→ı`):直接 `toLowerCase()` 会得到 `i` + 组合
  附加符,永远匹配不到 ASCII,`İyi akşamlar` 这类套话就这样漏网。
- 计数按码点(`Array.from`),emoji 不会被劈成半个;悬念句另有 30 字硬闸
  (检测链路会 `slice(0, 30)`,超了会被无声截断)。
- **刻意不判「承诺是否兑现」**:兑现判定需要全片文本,发布链路手上只有 300 字节选,
  拿它判会造出假的「没兑现」;也不判 too-short(一个词的合法钩子会被误伤)。

## 一次返工(只在有问题的时候花)
发布文案生成完后先过本地质检:
- 干净的一批 → **一次调用都不多花**,常态路径成本不变;
- 有命中 → **恰好一次**返工调用,只把点名条目送去重写,与首轮共用同一个超时
  (总时长仍受 90 秒约束,不是翻倍);返工结果只有**真的变好**才覆盖原稿,而且是
  逐条比:没变的、问题没变少的、写了没被点名 id 的,一律丢掉;
- 返工失败、超时、吐垃圾 JSON、上游取消之外的一切异常 → 退回首轮成果(fail-open);
  上游取消照旧上抛,取消契约不变。

## 评审顺手改标题(`titleFix`)
stage-1 的标题没有第二次生成(为标题再调一次模型不值),但 stage-2 评审本来就在读
每条片子:评审多了一个可选字段 `titleFix`(评审觉得标题套话/超长/风险就写出改法)。
只有它能通过同一道本地质检、且与现标题不同时才采纳;评审没给或改坏了就不动。

## 变体包装去重
`expandClipSpecs` 从「只丢一字不差的标题」升级为:与原版或已保留兄弟近乎同一句话、
或钩子角度已经被占的包装直接丢掉。顺序与封面分峰不受影响(丢掉的那版不占版本号)。

## 已知缺口(不在本版)
- **没跑过真实 LLM 端到端**:教义接线、质检判定、返工的各条失败路径都有单测,但一次
  真实的土耳其语直播出片仍未被跑过(本机没有调用真实端点)。
- 质检命中**不在界面里显示**:告警只作为返工输入留在发布链路内部,不进 `clips.json`
  也不进界面(避免快照漂移);想看见哪条被点名,目前只能看模型调用日志。
- stage-1 标题的本地质检只在评审给了 `titleFix` 时才起作用;模型首轮写出套话标题、
  评审也没改的那条,本版不会自动补一次生成。

本地验证:类型检查(node + web 两套配置)通过;1,474 项测试通过、12 项跳过,新增
48 项(教义块三语齐全/无 CJK 泄漏/不含时长档位字符串、质检的真阳性与假阳性、返工的
全部分支、`titleFix` 采纳与拒绝、变体去重)。18 项 ffmpeg 用例失败全部是本机沙箱
不能写系统临时目录(`Permission denied`)导致,与本版本无关。

## English
- **The gap**: prompts only bounded titles and hook lines by length — nothing taught
  the model how to write them, and nothing checked the result. Generic openers
  ("in this video…", "bugün sizlere…"), over-cap lines, one-pattern batches, hashtags
  inside titles and platform risk terms all shipped as written.
- **A writing doctrine** (`src/core/hook-craft.ts`, new): five mechanisms — counter-
  intuitive reveal, stop-doing imperative, direct question, result gap, pain-point
  callout — each native in zh/tr/en with a bad→good example, plus four principles
  (open exactly one gap, concrete beats abstract, the first three words decide it,
  promise only what the clip pays). Appended to every prompt that produces text the
  model writes itself: stage-1 title, moment, reviewer teaser, publish title and
  variant packaging. The blocks deliberately contain no length-tier strings, because
  `highlightSystemPrompt` rewrites those strings in place.
- **A local quality gate** (`src/core/hook-quality.ts`, new, no API): empty, too-long,
  generic opener, hashtag in the title, platform risk term (reusing the lint rule
  table), near-duplicate titles in a batch (Dice over char bigrams for zh, filtered
  word tokens for tr/en) and repeated hook angle. Turkish folds with an explicit map
  (`İ→i`, `I→ı`) because plain `toLowerCase()` yields `i` plus a combining dot and
  never matches ASCII; counts use code points; teaser lines carry an extra 30-unit
  tripwire matching the pipeline's `slice(0, 30)`. It deliberately does not judge
  payoff — the publish path only holds a 300-character excerpt.
- **One rework call, only when something is flagged**: a clean batch costs nothing
  extra; otherwise exactly one rework call, flagged ids only, sharing the first call's
  deadline, with rewritten titles accepted only when they strictly reduce the flagged
  problems. Failures, garbage JSON and unrelated exceptions fall back to the first
  pass; upstream abort still propagates.
- **Reviewer `titleFix`**: an optional field on the stage-2 verdict, adopted only if it
  clears the same gate and differs from the current title.
- **Variant dedupe**: packagings whose title is near-identical to the original or a
  kept sibling, or whose hook angle is already taken, are dropped.
- **Known gaps**: no real end-to-end LLM run was done; gate hits are not surfaced in
  the UI or `clips.json` (they stay inside the rework path); a stage-1 title that is
  both weak and left unfixed by the reviewer gets no automatic second generation.
