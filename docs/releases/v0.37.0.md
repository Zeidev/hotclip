# HotClip v0.37.0 — 土耳其语判据补齐:品类与本地文本数据

## 品类判据:土耳其语有了自己的版本
- 此前 18 个直播品类只有 zh/en 两版判据,提示词层直接写明「tr 仍注入 en」——
  土耳其语创作者选「带货直播」拿到的是英文判据,`[Stream type & criteria]` 也是
  英文字头。现在 **18 个品类都有原生土耳其语判据段**:标题行改为
  `[Yayın türü ve ölçütler]`,正文是英文版的土耳其语原生重写,不是逐字直译。
- 中文分区名(B站「虚拟主播」「电台」这类)在英文版里已经去掉过一轮,土耳其语版
  一律不出现——土耳其语观众认不出这些词。有测试守住这条(tr 文本里不许出现 CJK)。
- 审阅台与「监听文件夹」弹窗的品类下拉也一样:选 `tr` 界面现在显示
  「Canlı satış / alışveriş」「Evcil hayvan」,而不是英文名。
- 文本放在 `GENRE_LABEL_TR` / `GENRE_CRITERIA_TR` 两张 `Record<GenreId, string>` 表里,
  没有塞进 18 个预设字面量——漏一个品类在编译期就红。
- zh/en 的输出**逐字节不变**:判据文本与中文标题行一个字没动。

## 土耳其语本地文本数据
- **填充词**:`ee / eee / ıı / ııı / hıı / hımm` 进跳剪的强制切点。`şey / yani /
  hani / işte` 故意不收——它们是实词(「o şey」里的 şey 是名词),删掉会丢意思,
  与中文不收「然后/那个」同一个理由。
- **实用密度**:步骤词(ilk olarak / ardından / son olarak)、清单结构
  (「3 yöntem」「üç ipucu」「3 hata」)、方法论词(püf noktası / rehber / nasıl
  yapılır)补齐。裸 `adım`(也是「我的名字」)与裸 `yol`(在 yolcu/yolculuk 里都命中)
  不收,避免扫到日常口语。
- **屏蔽词默认表**:加土耳其语脏话。**同时修掉一个真 bug**——整词判定用的是
  ASCII `[a-z0-9]`,含 `ı/ş/ğ` 的词会被当成「非拉丁语」走子串匹配,于是屏蔽
  `göt` 会把 `götür`(拿走)一起切掉。判定改为 Unicode 拉丁字母口径后,
  「göt 命中、götür 不命中」有测试钉住。
- **主播口令**:`burayı kliple / şunu klip yap / hadi klip al / bu kısmı klip çıkar`。
  土耳其语侧不能用 `\b` 卡词首(ş/ı/ğ 在 JS 眼里不是单词字符),所以指代与动词都
  写成完整词形,`kliple` 后面显式加边界,免得 `klipler`(剪辑们)误命中。
- **违禁词 lint**:新增 8 组土耳其语规则(绝对化用语 / 疗效宣称 / 担保式承诺 /
  收益承诺 / 虚构紧迫感 / 站外导流 / 权威背书 / 迷信博彩),依据是土耳其《商业广告与
  不公平商业行为条例》与 RTÜK 对健康类宣称的限制;类别名也写成土耳其语
  (`En üstünlük iddiası`、`Sağlık beyanı`),因为告警是给土耳其语创作者看的。
  中文规则一条没改,两组正则互不干扰(CJK 规则扫不到土耳其语,反之亦然)。

## 已知缺口(不在本版)
- 出片质检的**告警句式仍是中文**:`qa.ts` 的风险词告警长这样
  `发布物料命中平台风险词:「en iyi」(En üstünlük iddiası·标题)`——类别已经是
  土耳其语,外层句式还是中文。这是一处独立的本地化,本版没动。
- 本版**没有跑过真实 LLM 端到端**:土耳其语判据与提示词的接线有单测(注入段是
  土耳其语、无 CJK 泄漏、en/zh 输出不变),但一次真实的土耳其语直播出片仍未被跑过。
- ASR 侧未变:内置 sherpa 档在土耳其语上实测 40% WER,`whisper-large-v3-turkish`
  3.3% WER(见 `docs/whisper-multilingual.md`)。

本地验证:类型检查(node + web 两套配置)通过;1,421 项测试通过、12 项跳过,新增
29 项(品类三语、填充词、实用密度、屏蔽词整词、口令、lint 规则)。18 项 ffmpeg 用例
失败全部是本机沙箱不能写系统临时目录(`Permission denied`)导致,与本版本无关。
渲染层用浏览器预览核对过:界面语言切到 tr 后,品类下拉 18 项全部显示土耳其语名。

## English
- **Turkish genre criteria**: all 18 stream genres had only zh/en criteria, and the
  prompt layer said so in a comment — a Turkish creator picking "live selling" got
  English criteria under an English heading. Every genre now has native Turkish
  criteria (heading `[Yayın türü ve ölçütler]`), written as Turkish rather than
  translated word by word, with the Chinese partition names kept out (a test
  enforces no CJK leaks into the Turkish text). The genre dropdowns in the review
  workbench and the watch-folder dialog show Turkish labels too. Text lives in two
  `Record<GenreId, string>` tables, so a missing genre fails at compile time, and
  the zh/en output is byte-identical to before.
- **Turkish text data**: hesitation fillers for jump cuts (`ee/eee/ıı/hıı/hımm`,
  deliberately excluding real words like `şey` and `yani`), utility-density
  patterns for steps and lists (`ilk olarak`, `3 yöntem`, `püf noktası`), Turkish
  profanity in the default mute list, voice clip commands (`burayı kliple`,
  `şunu klip yap`) and eight Turkish ad-regulation rule sets (absolute-superiority
  claims, health claims, guarantees, income promises, manufactured urgency,
  off-platform diversion, authority claims, superstition) with Turkish category
  names. This also fixes a real bug: the whole-word test was ASCII-only, so a term
  containing `ı/ş/ğ` was matched as a substring and muting `göt` cut `götür` too.
- **Known gaps**: the QA warning sentence around lint hits is still Chinese (the
  category inside it is Turkish), and no real Turkish export has been run against
  a live LLM endpoint; the Turkish ASR tier is unchanged (40% WER on the bundled
  sherpa model versus 3.3% for `whisper-large-v3-turkish`).
