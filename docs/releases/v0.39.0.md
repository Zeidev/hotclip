# HotClip v0.39.0 — 每个时间戳都落在真正渲染出来的成片上;没被复评的片段不再算「同意」;关窗不再丢草稿

## 问题在哪

这一版修的是同一个根:**代码里的时间轴和状态,和真正交出去的成片不是同一份**。

- 跳剪接缝用 `xfade` 交叉淡化,成片在每个接缝都缩短 `transitionSec`,但音效打点、
  运镜、爆点闪现、裁窗关键帧的映射都不扣它——每过一个接缝,后面所有事件就晚
  `transitionSec`;裁窗切换也发生在源片切点,而不是混合开始的位置。
- 复评批次失败或被截断时,缺评的 id 保持 `recommended:true`(旧路径的注释明写
  fail-open)——一次坏调用就变成「默认同意」,无人值守导出照样出片。
- 自动保存有 650ms 防抖,但检测进度是每几百毫秒一跳的 store 更新,每次都把计时器
  重置——持续检测时草稿一直落不了盘;关窗时计时器里的改动直接丢。

## 成片时间轴:交叉淡化的缩短量进到每一处映射(`reframe/index.ts` / `audio-peaks.ts` / `beat.ts` / `cut.ts` / `export.ts`)

- `mapToOutputTime`、`remapCropKeyframes`、`mapPeakEvents` 增加 `transitionSec`:
  每过一个接缝,后面的输出时间提前一个淡化时长。SFX 打点、自动运镜、爆点闪现、
  裁窗覆盖采样全部改吃同一份口径。
- 裁窗关键帧在**混合开始**处切换(`duration − xfade`),下一段起点也提前同样多——
  裁窗跑在混合后的画面上,切换要跟着混合走。
- `planBeatSnap` 用**放好之后**的段长累加输出位置:前一次吸附缩短了一段,下一个
  接缝的位置也必须跟着提前,否则吸附量基于不存在的时长。
- 交叉淡化由 `tri`(线性)改成 `qsin`(等功率):两段不相关人声在交叠区会掉约
  3dB,听感是每个接缝「顿一下」。冷开场接缝同样处理。
- 交叉淡化存在时,**接缝内部不再叠加首尾 afade**——`acrossfade` 已经包住接缝,
  再叠淡入淡出会在交叠区里凹一刀;只保留整条时间轴最外的两端。

## 复评:没看过 = 待审,不是通过(`highlight/detect.ts` / `hook-quality.ts`)

- 新增 `holdUnreviewed`:复评没覆盖到的 id 降为 `gate:"review"`、`recommended:false`,
  并写一条本地语言备注;`DetectOutcome.reviewIncomplete=true` 把「评审没看过」和
  「评审看过并放行」分开。复评整轮抛错也走这条路,不再 fail-open;用户主动取消
  仍然上抛。
- `titleFix` 增加**出处检查**(`ungroundedSpans`):改后的标题里出现的数字和引文,
  必须在片段文本里找得到(数字容千分位/小数点差异,如 `50.000` = `50000`);
  凭空补一个片段里没有的锚点——最像爆款、却兑现不了——一律拒绝。
- `no-anchor` 校准:反转/否定结构(「不是…而是」「bitmiyor」「wasn't」)本身就算
  锚点。实测 40 条真实标题里有 27 条只挂 `no-anchor`,其中大半正是这类结构,旧规则
  会让它们白跑一次返工。

## 土耳其语折叠进了关键词匹配(`hook-quality.ts` / `highlight/detect.ts`)

`fold()`(İ→i、I→ı)改为导出,商品词命中与关键词过滤不再用 `toLowerCase()`——
JS 的 `"İ".toLowerCase()` 会留下组合点符(U+0307),永远匹配不上字幕里的 `i`。

## 字幕行宽按真实渲染宽度算(`subtitle.ts`)

渲染宽度包含两部分旧代码没算的东西:渲染器在拉丁词之间**插入的空格**,以及关键词
高亮的 **108% 放大**。分组、助词断点、拉丁断点前缀、合并闸门现在统一用
`lineWidthUnits`;拉丁标定测试的期望同步修正(旧期望本身编码了「少算空格」的行为)。

## LLM 调用:判读与创作分开(`highlight/detect.ts`)

- 结构化抽取(爆点、复评)现在发 `response_format:{type:"json_object"}` 并把温度
  降到 **0.2**;创作类调用(标题/开场句/发布文案)保持 **0.6** 的措辞档。
- 不支持该参数的网关(`HTTP 400`)只丢**它点名的那一个**参数再发一次;报错泛化
  (`unknown parameter`/`unsupported`)时先丢 `response_format`——提示词里的 JSON
  说明还在,而 `enable_thinking` 关系到思考模型会不会吐空。每轮最多丢一个,必然收敛。

## 导出韧性(`export.ts`)

- 逐条隔离:一条坏片(素材损坏、某级滤镜失败、盘满)不再拖垮整批。失败原因记进
  `clips.json` 的 `failedClips`(id/标题/错误),其余成片与台账照常输出;一条都没成
  时把真实错误抛上去,而不是回一个「导出完成 0 条」。
- 取消信号接到封面抓帧、发布包封面适配、留证包复制——取消时这三处不再压着跑。
- 冷开场迷你片的人脸跟随复用正片的 `sourceAnalysis`:同一条片子两段裁窗不再建立在
  两份口径可能不同的探针结果上。

## 会话与草稿(`useDetection.ts` / `session-store.ts` / `App.tsx` / `main/index.ts`)

- 检测结果带世代号与逐句稿身份:项目已切换或逐句稿已替换时,晚到的结果整批丢弃,
  `detecting` 也只由当前那次收尾——旧跑完不再清掉新跑的标记。
- 自动保存只在**会落盘的字段**变化时重开防抖(`checkpointFieldsChanged`),检测进度
  这类瞬态 tick 不再把窗口一直往后推。
- 关窗握手:主进程先拦住 `close`,请渲染层把防抖里的草稿存掉,收到回执或等满
  2.5 秒(渲染层卡死/已崩)再真正关窗。

## 已知缺口

- `cover-quality.integration` 在本机失败(`candidatesRejected 1 < 2`);该测试的
  依赖(`cover-quality.ts`、`cover.ts`、`binaries.ts`、`runFfmpeg`)本版均未改动,
  判定为本机 FFmpeg 环境问题,与本次改动无关。
- 关窗握手只过了两套类型检查与新增的单测,**没有真的启动 Electron 关一次窗**。
- 没有跑真实 LLM 端点;JSON 模式与温度的效果只有请求体断言,没有「同一份转写两次
  跑出更一致的 id/分数」的实测。

## 验证

两套 tsconfig(`node` / `web`)类型检查通过;完整套件 **1,651 项通过、1 项跳过、
1 项失败**(即上面的环境项)。

## English

**Why**: the code's timeline and state were not the same as what actually ships.
An `xfade` shortens the output by its own duration at every splice, but
`mapToOutputTime`, `remapCropKeyframes` and `mapPeakEvents` never subtracted it,
so SFX cues, autozoom, peak events and crop switches drifted later by
`transitionSec` per seam; crop framing also switched at the raw source cut
instead of the blend start. The beat snapper accumulated the *old* segment
lengths, so one snap invalidated the position of the next splice. A failed or
truncated review batch left its ids `recommended`, making a broken call silent
consent that hands-off export published. And the 650ms autosave debounce was
reset by every detection-progress tick, so drafts never reached disk, while a
pending timer was lost on window close.

**Fixes**: all three mappers take `transitionSec`, `planBeatSnap` accumulates
placed lengths, cross-fades use the equal-power `qsin` curve, and interior edge
fades are dropped inside a cross-fade instead of cutting a dip into the
overlap. Unreviewed ids are held at the review tier (`recommended:false`,
`reviewIncomplete`), a `titleFix` must be grounded in the clip text (invented
numbers and quotes are rejected), and a reversal or negation counts as an
anchor. Turkish folding is used for product-keyword matching. Caption lines are
measured at their rendered width — inserted latin spaces and the 8% keyword
scale included. Structured LLM calls send `response_format:json_object` at
temperature 0.2, creative calls stay at 0.6, and a 400 drops exactly the
optional parameter the gateway names. Export isolates per-clip failures
(`failedClips` in `clips.json`, a real error when every clip fails), threads
cancellation into the cover and pack ffmpeg runs, and shares one
`sourceAnalysis` with the cold-open mini crop. The renderer drops detection
results from a superseded run or transcript, restarts autosave only on
persisted-field changes, and flushes one last checkpoint on window close
(capped at 2.5s).

**Known gaps**: the `cover-quality.integration` failure is a local FFmpeg
environment issue (none of its dependencies changed); the close handshake has
type checks and unit tests but no real Electron shutdown; and the JSON-mode
temperature change has request-body assertions only, not a live-endpoint rerun.

**Validation**: both tsconfigs typecheck clean; 1,651 tests pass, 1 skipped, and
the single failure is the environment item above.
