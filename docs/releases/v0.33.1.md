# HotClip v0.33.1 — Whisper.cpp GPU 档可在设置页接线

## 设置页直接选二进制与模型

- 设置 → 存储 新增 **Whisper.cpp (GPU)** 区块:分别选择 `whisper-cli` 可执行文件与 ggml 模型,路径保存在本机 `settings.json`,桌面用户不再需要配置环境变量。
- 环境变量 `HOTCLIP_WHISPER_CPP_BIN` / `HOTCLIP_WHISPER_CPP_MODEL` 仍然优先(脚本与 CI 用);界面会标注「来自环境变量」。
- 未配置时,转写引擎卡片直接显示「需配置 · 设置 › 存储」,不再等到开始转写才报错;清除按钮一键取消接线。
- 解析顺序为「环境变量 → 已保存设置」,并新增空值/损坏设置文件的回归覆盖。

## 文档:土耳其语实测

- 多语种档新增土耳其语实测对照:whisper.cpp + `ggml whisper-large-v3-turkish` q5_0 取得 **3.3% WER / 0.9% CER**;自带 sherpa 档目前 **40% WER**(28 秒识别窗口切断句子,属已知待修问题),因此土耳其语请走 fine-tune 档。
- CUDA 只在长音频上有收益(Pascal 约 25 秒固定启动开销):117 秒音频 turbo 2.6×、large-v3 微调 1.31× 实时;CUDA 12.4 优于 11.8。
- 修正此前「CUDA 更慢」的结论——那组数字来自 13.4 秒短片,固定开销占主导。

本地验证:类型检查通过,1,324 项测试通过(1 项环境相关的 ffmpeg 封面黄金集用例失败,与本版本无关)。

## English

- Settings › Storage now has a **Whisper.cpp (GPU)** section: pick the `whisper-cli` executable and the ggml model; the paths are stored in `settings.json`, so desktop users no longer need environment variables (which still take precedence when set).
- The transcription engine card warns "Needs setup · Settings › Storage" instead of failing only once transcription starts, and a Clear button un-wires the pair.
- Resolution order is environment → saved setting, with regression coverage for blank values and a corrupt settings file.
- Docs: measured Turkish comparison — `ggml whisper-large-v3-turkish` q5_0 reaches 3.3% WER / 0.9% CER, while the bundled sherpa tier sits at 40% WER (its 28 s ASR window cuts sentences; known issue) and should not be used for Turkish.
- Corrected the earlier "CUDA is slower" conclusion: those numbers came from a 13.4 s clip where the ~25 s fixed CUDA startup dominates; on 117 s of audio CUDA runs 2.6× (turbo) / 1.31× (large-v3 fine-tune) realtime, and CUDA 12.4 beats 11.8.
