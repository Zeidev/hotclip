# HotClip v0.34.0 — 土耳其语原生高光链路、钩子兑现复评、预览不再卡死
## 土耳其语:原生提示词 + 拉丁字幕字体
- 提示词语言此前是二元的(zh,否则 en),土耳其语转写被塞进英语钩子模板,而那些
  公式在土耳其语里并不成立。现在按转写内容判定 **zh / tr / en**(引擎语言,或
  auto 时按土耳其语特有字母),tr 有自己的一整套:选段、对抗复评、信号时刻通道、
  多段拼接、口播备注与证据标签。钩子清单是原生土耳其语而非翻译
  (`Bunu kimse söylemiyor ama...`、`... yapmayı bırak`、
  `Herkes ... sanıyor, gerçek şu ki...`),并带一条评论钩类目与时长档位的 tr 改写。
- 字幕字体:内置唯一字面 Source Han Sans SC 不含 Latin Extended-A 字形,土耳其语的
  `ı İ ğ Ğ ş Ş` 会掉到 libass 系统回退字体,字重与字宽都变了。新内置 **Noto Sans
  (OFL)**:拉丁文为主的片子用它,CJK 为主的仍用 Source Han Sans SC。
- 已知缺口:辅助段落(品类 / 产品 / 简介 / 参考 / 审阅记忆 / 发布表现附录与视听
  信号清单)在土耳其语下仍是 zh 或 en。

## 复评多问两件事:开头许诺兑现了吗、结尾能不能接回开头
- **兑现分 0-100**:开头抛的悬念/承诺在片内有没有落地。平台按完播排序,没兑现的
  钩子是观众划走最常见的原因,所以低于 45 分**只降不升**(与规则门同样是降级),
  归一化后排在所有可发布片之后,原因在候选提示条与检查器里可见。
- 30 秒以内的片子再看结尾是否**接回开头**:干净闭环 +4 分(在归一化之前算),
  重看就是白送的观看时长。
- 两个字段都是可选的:模型什么都没吐时打分与门判与历史版本完全一致;loop 不是
  布尔值就忽略。检查器多了第五条分数条和 loop 徽章(两个语言都译了)。

## 剪辑预览不再卡死
- `serveMedia` 补上真正的背压:队列满就暂停文件流,消费方 pull 了再续。以前同一份
  大素材的三个视图(主画面 / 裁切 / 审阅)会把整个文件排进内存,应用锁死到只能
  强制关闭。
- 审阅台播放头改为直接写 DOM,不再每帧重渲染整个弹窗;拖拽手柄时的 seek 合并成
  每动画帧一次——此前 `pointermove` 每次都 seek,解码器被拖垮。
- 审阅弹窗打开时暂停工作台预览,裁切窗同步节流到 250 毫秒:此前三个解码器同时在跑。
- 硬编码中文:内置方案名、样式预设名、LLM 供应商标签改走语言键,中文兜底名跟随
  界面语言;Paraformer 引擎标签与 main/core 报错信息改成中英双语。新增回归测试钉住。

本地验证:类型检查与打包通过;1,343 项测试通过,另有 12 项跳过。18 项 ffmpeg 用例
失败全部是本机沙箱不能写系统临时目录(`Permission denied`)导致,与本版本无关。

## English
- **Turkish highlight path**: prompt language is now decided per transcript
  (zh / tr / en) instead of "zh, else English", and Turkish gets its own native
  hook list plus selection, adversarial review, signal-moment, stitching, speaker
  note and evidence labels — translated formulas do not exist in Turkish.
- **Latin caption font**: Source Han Sans SC has no Latin Extended-A glyphs, so
  Turkish `ı İ ğ Ğ ş Ş` fell through to a libass system fallback with different
  weight and metrics. The new bundled Noto Sans (OFL) handles Latin-script clips;
  CJK-dominant clips keep Source Han Sans SC. Known gap: the supporting sections
  (genre / product / brief / reference / review-memory / performance-memory and
  the audiovisual signal list) still render in zh or en for Turkish runs.
- **Hook payoff + loop verdict in the stage-2 review**: the reviewer scores
  whether the opening's promise is paid off inside the clip (0-100) and, for
  clips ≤30 s, whether the ending leads back into the opening. An unpaid hook
  (below 45) is demoted only — never promoted — and lands below every publishable
  clip after rank normalization, with the reason visible in the tooltip and
  inspector; a clean short loop scores +4. Both fields are optional, so a model
  that returns neither leaves scoring and gating untouched.
- **Clip preview freezes fixed**: `serveMedia` now has real backpressure (pause
  the file stream when the queue is full, resume on pull) — three media views of
  one large source used to queue up the whole file in memory and lock the app up.
  The review playhead is painted straight to the DOM instead of being React state
  (it re-rendered the whole modal every frame) and drag seeks are coalesced to one
  per animation frame; the workbench preview pauses while the review modal is open
  and crop syncing is throttled to 250 ms.
- **Hardcoded Chinese localized**: built-in scheme names, brand preset names and
  LLM provider labels move to locale keys and their fallbacks follow the UI
  language; the Paraformer engine label and the main/core error messages are
  bilingual. Regression suite added.
